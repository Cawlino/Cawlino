# Architectural Decision Records (ADRs) - Cawlino

## ADR-001: Padrão Resumido de 4 Tópicos para Projetos em Destaque
- **Status:** Aceito
- **Contexto:** O projeto Vitrine Web estava excessivamente detalhado e longo em comparação com outros projetos, desbalanceando visualmente o perfil. O novo projeto UPM também precisava ser integrado de forma sucinta.
- **Decisão:** Padronizar os projetos em destaque com estrutura objetiva contendo descrição de uma linha e tópicos diretos (Tech, Destaque/Arquitetura, etc.), mantendo a Vitrine Web resumida e inserindo o UPM com badge e resumo conciso.
- **Consequências:** Leitura rápida, escaneabilidade excelente e perfil profissional equilibrado.
